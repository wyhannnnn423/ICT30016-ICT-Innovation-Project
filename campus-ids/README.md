# Campus IDS - ICT30016 (ICT Innovation Project)

A lightweight, AI-driven Intrusion Detection System designed for campus networks. This system captures real-time network traffic via Suricata, extracts IPv4 flow features in memory, and performs unsupervised anomaly detection using an Isolation Forest machine learning model. Threats are pushed instantly to a real-time web dashboard using WebSocket integration.

## ⚙️ Prerequisites
1. **Python 3.8+**
2. **Suricata (Windows)**: Must be installed with **Npcap** (WinPcap API-compatible Mode) to capture local area network traffic on Windows.
3. **Suricata Configuration**: Ensure the `eve-log` output is enabled and configured to log `flow` event types in your `suricata.yaml`.

## 📦 Installation
Navigate to the project root directory and install all required standard and asynchronous networking dependencies:
```bash
pip install pandas scikit-learn joblib flask flask-socketio eventlet
```

## 🚀 Execution Workflow

### Step 1: Start the Suricata Capture Engine
Suricata requires elevated privileges to bind to your network interface. Open an **Administrator PowerShell**, identify your local IPv4 address (e.g., `192.168.50.190`), and start the engine:
```powershell
cd "C:\Program Files\Suricata"
.\suricata.exe -c suricata.yaml -i <YOUR_REAL_LAN_IP>
```
*Note: Leave this terminal open. Suricata is now running in the background and writing flow events to `C:\Program Files\Suricata\log\eve.json`.*

### Step 2: Train the AI Model (Initial Setup Only)
If you need to train a new Isolation Forest model based on captured baseline traffic, execute the following pipeline in a standard terminal:
```powershell
# 1. Extract features from the existing eve.json log to a CSV format
python suricata/read_suricata_flows.py --input "C:\Program Files\Suricata\log\eve.json" --output data/suricata_flow_features.csv

# 2. Train the Isolation Forest model and generate the scaler
python model/train_model.py --input data/suricata_flow_features.csv --model_out model/ids_model.joblib --scaler_out model/ids_scaler.joblib
```

### Step 3: Launch the Real-Time AI Dashboard
Open a new standard terminal. Start the Flask application, which automatically spawns a background thread to tail `eve.json`, run live AI predictions, and emit alerts via Socket.IO.
```powershell
cd dashboard
python app.py
```
Open your web browser and navigate to: **http://127.0.0.1:5000**

### Step 4: Simulate a Cyber Attack (Security Testing)
To verify the detection latency and model sensitivity, open another terminal to run the local testing script.
*⚠️ Important: Ensure you edit `simulate_attack.py` and set `TARGET_HOST` to your real LAN IP (not `127.0.0.1`) before executing.*
```powershell
python simulate_attack.py
```
Anomalies generated by the rapid port scan payload will be flagged by the Isolation Forest model and pushed instantly to the web dashboard without requiring a page refresh.

## 🛑 Safe Shutdown Procedure
To gracefully shut down the system and prevent file corruption:
1. **Dashboard:** Go to the terminal running `app.py` and press `Ctrl + C`.
2. **Suricata Engine:** Go to the Administrator terminal running `suricata.exe` and press `Ctrl + C`. Wait 3-5 seconds for Suricata to finish flushing the final `eve.json` logs and output `Engine shut down`.

## ⚠️ Troubleshooting
* **Permission Denied Errors:** If Suricata crashes immediately with log permission errors, ensure your PowerShell is running as Administrator.
* **No Alerts Appearing:** Ensure you started `app.py` *before* running `simulate_attack.py`. The file-tailing script utilizes `os.SEEK_END` to only analyze *new* traffic generated after the dashboard engine starts.
* **Zero Traffic Captured:** Ensure your `TARGET_HOST` in the attack script is your physical LAN IP. Windows Npcap cannot capture `127.0.0.1` (loopback) traffic by default.
